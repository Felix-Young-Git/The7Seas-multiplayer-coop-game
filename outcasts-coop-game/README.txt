THIS IS THE README FOR THE MULTIPLAYER COOP GAME OUTCASTS

To play the game:

	- Currently, when running the game, godot runs 2 instances of the game, to turn this off go to
	  debug, then to custimaize run instances, then set to 1

	- One player will be the host, and so will click the "host" button
	- The other players must be on the same local network as the host, as port forwarding does not work becasue of CGNAT.
		- The other players will enter the host's local ip address, which can be found by typing "ipconfig" in the termain and
		looking for the IPV4.
		- Also the host will need to set up a port forwarding rule on their router for this to work
	- You can also run the game with the port "localhost" to test
